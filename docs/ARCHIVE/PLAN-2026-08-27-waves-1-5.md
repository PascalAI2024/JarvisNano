### Self-management safety contract

- Diagnose may read cockpit, Gemini live state, tasks, audio taps, sensors, and
  a bounded incident log.
- Safe repairs may set persisted volume/brightness, clear stale canvas/test
  ownership, restore a non-private dead session, or run a privacy-safe self-test.
- Repairs must never clear `privacy_paused` or `s_flip_muted`, invent
  credentials, change Wi-Fi power policy, write PMIC rails, or reboot on TX
  drops/low memory.
- Brightness is a user ceiling; moods may dim below it but never raise above it.
- Low contiguous memory refuses canvas/snapshot/OTA/self-test rather than
  making the TLS/voice failure worse.

### Doctor and paired-level contract

`jarvisctl doctor` reads, without mutation:

- `/api/cockpit`
- `/api/gemini/live`
- `/api/diag/tasks`
- `/api/audio/taps`
- `/api/sensors`
- `/api/operator/lease`
- `/api/logs?tail=16384`

Verdicts are ordered and mutually explicit:

1. `privacy-muted` — deliberate hold/flip; healthy, no repair.
2. `operator-active` — Codex owns glass; no voice repair.
3. `session-dead` — Idle/Backoff/Fatal while not private.
4. `uplink-dropping` — `tx_drops` rising or queue nonzero.
5. `memory-critical` — largest internal block <8 KB or PSRAM <2 MB.
6. `display-fault` — flush errors rising or FPS <12 for 3 s.
7. `audio-fault` — stuck DAC mute, clipping, or failed self-test.
8. `tool-fault` — configured JarvisMCP with non-OK typed response.
9. `ok`.

Log triage preserves counts and the last causal window for:

- WebSocket backpressure/closed transport
- session death/reconnect
- display flush
- OTA/rollback
- memory/allocation
- audio feeder/clipping
- physical input/action
- JarvisMCP request/response

Repeated identical transport lines collapse to
`{signature,count,first_ms,last_ms}` so the 128 KB ring retains gestures and
root-cause transitions.

Paired level control is:

```json
{"volume": 10, "brightness": 10}
```

through `POST /api/device/levels` with token + control header. Fields are
optional, bounded 10..100, persisted, and receipt-captioned. Volume updates the
same `s_out_vol` state used by swipes. Brightness is a ceiling multiplied by the
mood target; DREAM/WHISPER may dim below it. Neither field changes voice,
privacy, operator ownership, Wi-Fi, PMIC rails, or session state.

`doctor --repair` is allowed only when not private, not face-down, not in Codex
mode, and not inside consent/ask. It may re-arm a non-private dead session,
clear expired canvas/test ownership, restore a stuck DAC, or run a bounded
self-test. Low-memory/uplink-drop verdicts are report-only.
